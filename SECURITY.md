# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of VidhyaPath Adaptive Learning seriously. If you believe you have discovered a security vulnerability, please report it responsibly:

1. **Advisory**: Please open a private security advisory through the repository's Security tab on GitHub.
2. **Details**: Include steps to reproduce, impact assessment, and affected routes or modules.
3. **Timeline**: Maintainers review and respond to valid disclosures promptly.
